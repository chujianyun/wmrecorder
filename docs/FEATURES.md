# 功能范围与验收矩阵

依据：[产品页](https://zh.okaapps.com/product/1592987853)、[官方操作指南](https://zh.okaapps.com/blog/61a47d99d42eee0aaef3e71d)。独立实现公开功能，使用原创界面与名称，不使用原产品商标或私有代码。

| 功能 | 实现路径 | 验收方式 |
| --- | --- | --- |
| 全屏、多显示器、区域 | ScreenCaptureKit，区域拖选和精确坐标 | 实际文件尺寸、时长和画面 |
| 单窗口、多窗口、应用后台录制 | SCContentFilter | 测试窗口被遮挡时仍能输出 |
| 系统音频、麦克风、混音及独立音轨 | SCStream / AVCaptureSession + AVAssetWriter | 音轨数、采样率、非零声音 |
| 摄像头录制、设备选择、镜像 | AVCaptureSession + Core Image | 实际相机输出 |
| 摄像头画中画 | 原生合成，位置与大小可调 | 屏幕与摄像头同时可见 |
| 参数 | 分辨率、15–60 fps、质量、倒计时、定时停止、鼠标和点击提示 | 参数测试与真实媒体探测 |
| 控制 | 开始、暂停、恢复、停止、计时、菜单栏、全局快捷键 | 暂停不计入输出时长 |
| 媒体库 | 搜索、排序、预览播放、重命名、定位、移出列表、移到废纸篓 | UI 与文件行为 |
| 编辑与压缩 | 时间截取、画面裁剪、尺寸、帧率、画质、音量、声道/音轨、格式 | ffprobe 与解码检查 |
| 偏好 | 输出目录、录制参数持久化、完成后显示、可修改快捷键 | 重启保存 |
| 授权与交付 | 正式 bundle 内授权，同一证书/DR，原子安装 | 更新前后权限及 DR 实测 |

平台：macOS 15+，当前交付 Apple Silicon。本机使用系统框架采集，安装的 FFmpeg 负责媒体编辑和导出；不安装音频驱动。系统隐藏/最小化窗口的可捕获性遵从 ScreenCaptureKit 能力。测试记录如实区分通过、失败、阻塞。
