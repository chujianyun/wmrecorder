# 实现说明

## 采集与时间线

ScreenCaptureKit 按显示器、区域、窗口或应用构建过滤器，输出视频和系统／麦克风音频。摄像头与不依赖屏幕的麦克风使用 AVCaptureSession。所有媒体回调汇入同一串行队列，AVAssetWriter 分轨写入临时 MOV。

首帧／首个音频样本到达后才进入录制状态。暂停时停止向编码器提交数据，恢复时统一扣除暂停的主机时钟时长，保持各轨时间戳一致。停止使用结束会话时间补足最后一帧，再等待写入完成。

Core Image 按原始宽高比合成视频和摄像头，黑边与边框明确分离。镜像与画中画合成是纯函数，由已知颜色的像素测试验证。设备测试另外检查原始相机样本是否近乎全黑，避免“样本数非零但不可见”被误判为成功。

## 文件安全

FFmpeg 由 `Process.arguments` 传入参数数组，不拼接 shell 命令。拒绝以输入路径作为输出，使用 `-n` 拒绝覆盖已有文件。编辑和录制均保留原素材，只有最终输出可探测且时长有效后才移除本次录制的内部临时文件。普通删除使用系统废纸篓。

正在录制／导出／自检时，安装程序拒绝中断。退出录制会先尝试正常保存。进程退出验证使用操作系统存活状态，避免 NSRunningApplication 的缓存属性把已退出进程误判为仍然运行。

## 授权与签名

申请权限的进程即正式安装应用，没有单独授权 helper。签名证书指纹保存在本机忽略文件；bundle identifier、安装位置和代码签名身份保持不变。更新验证新包满足旧包完整 DR，表达式通过 `codesign -R '= ...'` 传入，不减弱证书约束。

首次实际 ScreenCaptureKit 访问还可能触发 macOS 额外确认，因此授权页面提供实际采集验证。不得通过修改系统权限数据库、临时换签名或系统安全设置来规避提示。

## 可重复验证

应用 Info.plist 记录源代码与构建配置的 SHA-256 指纹，设备自检将同一指纹写入结果，便于核对测试与安装版本。录制画面、原始日志与签名证书详情留在本机；可提交的测试记录只包含脱敏结果和限制。
