# WMRecorder · 悟鸣录屏

原生 macOS 录屏、录音、摄像头录制与视频编辑工具。根据 [Omi 录屏专家公开产品功能](https://zh.okaapps.com/product/1592987853) 独立实现，使用自己的名称、界面与代码。

## 功能

- 全屏、多显示器选择、拖选或精确输入区域；单窗口、多窗口及应用录制。
- 系统内录与麦克风，可选输入设备、分别调整音量，混音、独立音轨或单声道。
- 摄像头独立录制、镜像、实时预览；屏幕录制叠加摄像头，可选四个位置和大小。
- 720p、1080p、4K 或自定义偶数尺寸，15–60 fps、三档画质、鼠标与点击指示。
- 倒计时、指定录制时长、暂停／恢复、菜单栏控制、录制提醒和可修改的全局快捷键。
- 媒体库支持搜索、按名称／时间／时长／大小／类型排序、播放、重命名、定位、移出列表和移到废纸篓。
- 时间截取、画面裁剪、缩放、帧率、压缩、音量、音轨与声道调整；支持 MP4、MOV、MKV、GIF、M4A、MP3、WAV。
- 正式应用内授权和本机自动自检。失败的原始素材保留，导出不覆盖原文件。

当前机器的摄像头返回接近全黑的画面，实景验收尚未通过。其余验证结果和待人工项见 [首次交付测试记录](docs/test-reports/2026-09-12-first-delivery.md)。

## 使用

安装后打开 `/Applications/WMRecorder.app`。首次进入「授权与测试」，允许需要使用的屏幕、麦克风和摄像头权限，然后点击「检查实际采集」。macOS 可能另外显示首次或周期性屏幕访问确认，请在系统提示中处理；仅开启设置中的开关不能保证所有确认都已完成。

在「录制」中选择来源与参数，点击底部「开始录制」。开始后可从窗口底部或菜单栏暂停、继续、停止。默认保存到用户影片目录下的 `WMRecorder`。录制参数与输出目录会自动保存。

摄像头模式或画中画启用后，可以先点击「预览摄像头」。如果输入接近全黑，录制页会提示检查光线、遮挡或设备选择。自检收到视频帧不等于摄像头实景画面通过。

媒体库右键菜单提供文件操作。编辑页先选择素材，调整开始／结束时间和画面参数，点击「预览效果」查看处理后的前 5 秒，再导出为一个新文件。结束时间 0 表示直到结尾。没有视频的素材请导出音频格式；仅音频模式不能选择静音。

「独立音轨」用于视频文件保留系统与麦克风轨道；音频文件导出会混合选中的音轨。只需某条音轨时，可在编辑页单独选择。

## 默认快捷键

| 操作 | 快捷键 |
| --- | --- |
| 显示录制窗口 | Control + Command + W |
| 全屏／区域／摄像头模式 | Control + Command + 1 / 2 / 3 |
| 开始 | Control + Command + R |
| 暂停／恢复 | Control + Command + P |
| 停止保存 | Control + Command + T |
| 媒体库 | Control + Command + L |

在偏好设置中点击组合键重新设置，Esc 取消。已被其他应用占用的组合键会显示冲突提示。关闭主窗口后，应用仍可通过菜单栏或快捷键打开。

## 构建与安装

当前开发目标为 macOS 15+，需 Swift 6 工具链、命令行开发工具及 FFmpeg。当前安装使用本机 Homebrew 的 FFmpeg，应用会检查依赖，不会静默下载或安装音频驱动。

```bash
brew install ffmpeg
mkdir -p .local
security find-identity -v -p codesigning
# 将选定的可持续使用证书 SHA-1 指纹写入此本机文件；不要使用 '-'。
printf '%s\n' 'YOUR_PERSISTENT_CERTIFICATE_FINGERPRINT' > .local/signing-identity
swift test
./scripts/build.sh
./scripts/install.sh
```

构建脚本固定 `com.wuming.wmrecorder` 标识，安装到 `/Applications/WMRecorder.app`，拒绝 ad-hoc 签名。更新前检验新产物满足旧安装的 designated requirement。签名配置只保存在 Git 忽略的 `.local`，不提交证书、账号或私钥。证书不可用或身份不兼容时停止更新，保留旧安装。

安装程序先核实运行状态并请求空闲应用正常退出；正在录制、倒计时、导出或测试时拒绝中断。新版先暂存校验，旧版移到本机备份位置，再完整替换安装。不会执行 TCC 重置，也不会删除用户设置或录制库。签名稳定不能取消 macOS 自己的周期性权限确认。

## 测试

```bash
swift test
# 单元测试后构建、稳定签名安装，并在实际安装包中运行设备自检：
./scripts/test-installed.sh
# 可在自检后追加 60 秒录屏测试：
./scripts/test-installed.sh --stress-seconds 60
```

也可以在应用「授权与测试」中点击「运行完整自检」。自检实际使用屏幕、音频和摄像头，会播放低音量测试音，并生成本地媒体、JSON 与 Markdown 记录。终端测试保存在 `.local`，应用按钮测试保存在用户 Application Support 内。**测试素材和个人环境信息不提交 Git，也不上传。**

测试覆盖参数边界、输入文件保护、真实转码、音量变化、声道与音轨、像素级镜像和画中画；设备自检覆盖录屏、区域、被遮挡窗口、多窗口、应用、4K／60 fps、音频、摄像头、暂停、定时停止及导出。摄像头黑场会报告失败，不能用帧数掩盖。

测试报告位于 [docs/test-reports](docs/test-reports)。硬件条件、系统确认、单显示器环境等限制会在报告中单列，不代表所有外接硬件或其他 macOS 版本都已测试。

## 恢复与边界

- 录制先写入输出目录的 `.sessions`；保存／混音失败时保留素材，可通过 Finder「前往文件夹」进入此目录，用编辑页重新打开可播放的文件。分片写入有助于异常中断恢复，但无法保证磁盘故障或任意损坏的恢复。
- 视频使用 H.264，音频使用 AAC；FFmpeg 在保存时进行帧率、音量和音轨处理。长片停止后需要一定的导出时间。
- 单窗口可在被其他窗口遮挡时独立录制；最小化、关闭窗口、受保护视频内容和系统禁止捕获的画面受 macOS 限制。
- 多窗口按选中显示器上的位置合成；跨显示器选择需逐一选择对应显示器。当前机器只实际测试了一个显示器。
- 本机开发签名用于这台电脑的安装验证；没有宣称完成 Developer ID 公证、App Store 分发或跨机器免授权安装。

## 代码结构

`CaptureEngine` 负责屏幕／相机采集和媒体时间线；`VideoCompositor` 合成画面；`MediaTools` 使用参数数组调用 FFmpeg；`RecorderModel` 管理录制与文件状态；SwiftUI 页面与 AppKit 组件提供录制、编辑、热键和区域选择。自动测试与实际录制共用采集和合成实现。
